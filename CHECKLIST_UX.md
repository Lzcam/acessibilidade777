# Checklist UX — Sistemas Inteligentes

## 1) Programa escolhido
Foi utilizado o projeto já existente em HTML5, CSS3 e JavaScript sobre **Sistemas Inteligentes**.

## 4) Wireframe
A estrutura planejada da página é:

1. Cabeçalho
   - imagem do coelho
   - título
   - descrição curta
2. Barra de ferramentas
   - leitura em voz alta
   - aumentar/diminuir texto
   - alto contraste
   - Google Tradutor
3. Conteúdo principal
   - introdução
   - componentes-chave
   - aplicações atuais e futuras
4. Rodapé

## 5) Protótipo
O protótipo foi transformado em uma página funcional. Os controles da barra superior já possuem interação e o conteúdo está organizado para simular a experiência final.

## 6) UI
A interface foi refinada com:
- hierarquia visual de títulos;
- cartões para aplicações;
- layout responsivo;
- botões com estados visuais;
- espaçamento e tipografia consistentes;
- adaptação para celular.

## 7) Desenvolvimento
Arquivos:
- `texto.html` — estrutura HTML5;
- `style.css` — identidade visual e responsividade;
- `script.js` — interações e acessibilidade.

## 8) Acessibilidade
Foram implementados:
- link "Pular para o conteúdo";
- textos alternativos para imagem;
- HTML semântico (`header`, `nav`, `main`, `article`, `section`, `footer`);
- navegação por teclado com foco visível;
- leitura em voz alta usando Speech Synthesis;
- aumento e redução do tamanho do texto;
- modo de alto contraste;
- `aria-label` e `aria-pressed` nos controles;
- suporte a `prefers-reduced-motion`;
- layout responsivo para telas menores.
